# Client Setup Guide

## Prerequisites

- A computer (Windows, macOS, Linux, or Chromebook)
- A web browser (Chrome, Firefox, Edge, or Safari)
- Connection to the school LAN

## Steps

1. **Connect to the school network**
   - Plug in the Ethernet cable, or
   - Connect to the school Wi-Fi network

2. **Open a web browser** and navigate to:
   ```
   http://<SERVER-IP>
   ```
   Replace `<SERVER-IP>` with the IP address provided by your system administrator.

3. **Log in** with your username and password provided by the administrator.

4. **Bookmark the page** for easy access:
   - Press `Ctrl + D` (Windows/Linux) or `Cmd + D` (Mac)

## Offline Use

Once the page has loaded once, modern browsers can cache the frontend assets. However, **active data entry requires the server to be online**. If the server is offline, users will see a connection error.

## Mobile / Tablet Access

SMIS works on tablets and phones, but the interface is optimized for desktop screens (1024×768+). For the best experience:

- Use landscape orientation on tablets
- Pinch-to-zoom is supported but not recommended for data entry

## Troubleshooting

If you cannot access the system:

1. Verify you are connected to the correct LAN.
2. Ping the server: `ping <SERVER-IP>`
3. Ask the administrator to check:
   - Is the server powered on?
   - Is the SMIS service running?
   - Is the network cable connected?

See [TROUBLESHOOTING.md](TROUBLESHOOTING.md) for more details.
